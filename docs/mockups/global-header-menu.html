SF Tabs in the Salesforce global header

An alternative to the floating drawer: inject one item into Salesforce's own ul.slds-global-actions so it sits with Favorites, Global Actions, Help, Setup and Notifications. Styled with Salesforce's classes, so it should be indistinguishable from the Setup gear menu — which also means it follows Salesforce's theme, not the extension's.
