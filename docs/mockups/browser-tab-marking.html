Marking browser tabs — what Chrome and Firefox actually allow

Everything below is rendered at real tab scale. Verified against the Chrome and MDN extension docs in August 2026; sources listed at the bottom.

The short answer: neither browser lets an extension color an individual tab or draw a border around one. There is no API for it and no CSS reaches the browser chrome. What you can do is three things — repaint the favicon, rewrite the title, and put tabs in a tab group that carries a name and one of nine fixed colors. Firefox adds a fourth: it can recolor the entire window's chrome, though not one tab within it.

1 · Favicon — the only true per-tab paint surface

A content script swaps the page's <link rel="icon"> for a canvas or SVG data URL, so anything you can draw in 16×16 is available. This is what the extension in your screenshots is doing with its shapes, emoji and text overlays. Both browsers, no permission beyond the content script you already run.

2 · Title — free, and visible even when the tab is narrow

Setting document.title changes the tab label. It survives Lightning's own title updates only if you keep reapplying it, which means a MutationObserver on <title>. Worth knowing: it also changes what gets bookmarked and what appears in history.

3 · Tab groups — the closest thing to coloring a tab

Chrome's chrome.tabGroups and Firefox's browser.tabGroups (139+) can set a group's title, color and collapsed state. The group paints a colored strip behind its tabs and a labelled chip to their left. Requires the tabGroups permission, and grouping itself is done with tabs.group().

The catch: nine named colors, no hex — so an org's color has to be mapped to the nearest one. And a group is a run of adjacent tabs, so putting a tab in a group moves it.

4 · Firefox only — recolor the whole window

browser.theme.update(windowId, theme) accepts a windowId, so one window can be themed while others are left alone. Colors take any CSS value, including hex. The useful keys are frame (the strip behind the tabs), tab_selected, tab_text, tab_background_text and tab_line.

The catch: it is per window, not per tab. It only helps if you keep each org in its own window — which, given profiles already work per org, may suit how you work anyway.

What this rules out

The two things you asked about specifically — a background color on one tab, and a border around one tab — are not possible in either browser. Extensions cannot style the tab strip; the only pixels they own are the favicon. Every extension that appears to color a tab is either painting the favicon, using a tab group, or theming the window.
