Floating button & panel

Three directions for the on-page overlay, built on the SLDS-sourced --sft-* tokens so they match the popup. Today the trigger is a 20×36px edge tab and the panel is a flush 300px list showing every tab's full path. Toggle the theme to check both.

A · Edge drawer (evolution of today)

Keeps the docked-to-the-edge model, but the handle grows to 24×56 for a real hit target, the panel gets a radius and shadow so it reads as a surface, and paths drop to a badge plus name. Least disruptive; still competes with Salesforce's own right-edge utilities.

C · Command palette

Search-first. Type to filter, arrow keys to move, Enter to go — the fastest option once you have many tabs, and the only one that scales past a screenful. Paths appear only on the highlighted row, so the list stays quiet. Biggest departure, and the trigger still needs to exist for mouse users.
