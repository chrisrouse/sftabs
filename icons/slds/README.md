# SLDS Utility Icons

SVG icons vendored from the Salesforce Lightning Design System
(`@salesforce-ux/design-system`, `assets/icons/utility/`), licensed
under BSD-3-Clause © Salesforce.

Modification: `fill="#fff"` replaced with `fill="currentColor"` so the
icons inherit their color from CSS.

Usage: inline the SVG or reference the file; size with width/height and
color with the CSS `color` property on the wrapping element.
