Tabs

Tabs are the missing feature in Salesforce Setup. SF Tabs wouldn't exist without the original extension "Why Salesforce" extension. SF Tabs builds on the legacy of that extension.

*New Tabs*
New tabs can be added several ways. The fastest way is by using the Quick Add button. This button captures the current URL and determines if you're on a Setup page, an Object page, or somewhere else in Salesforce. It adds it to your custom tabs with just once click.

*Organize Tabs*


Tabs now also support colors, so if there are certain pages you go to often, you can add a subtle color to them so that they stand out better on your page. This is especially useful if you have a lot of tabs. Colors are only included in the Setup menu tabs and they don't carry over into the other menu locations.
